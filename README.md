# Disposal Intelligence Platform (DIP)

Find verified disposal facilities before your trucks leave the jobsite.

## Overview

The Disposal Intelligence Platform is a purpose-built solution for construction firms, waste transporters, and environmental services to locate, verify, and manage slurry disposal facilities.

### Primary Use Cases
- **Concrete Slurry Disposal**
- **Asphalt Slurry Disposal**
- **Mixed Construction Waste Slurry**

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Key Features

- **Market Intelligence Dashboard**: Real-time benchmarks for disposal costs and facility coverage.
- **Verification Pipeline**: Track the lifecycle of facility discovery and approval.
- **Facility Directory**: Searchable database of 1,420+ verified disposal locations.
- **Call Sheets**: Optimized scripts for facility outreach and capacity verification.
- **Facility Discovery**: Search for facilities by city, radius, and material type.
